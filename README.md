# 💌 Kartu Ucapan Sayang untuk Pasangan

Website kartu pos digital (*digital postcard*) sederhana, manis, dan interaktif untuk dikirimkan ke pasangan tercinta melalui GitHub Pages.

## ✨ Fitur
- **Bingkai Foto Polaroid**: Menampilkan foto pasangan secara permanen (cukup taruh file `foto-pasangan.jpg` di folder utama) atau bisa langsung diganti dari halaman web.
- **Pesan Sayang yang Bisa Dikustomisasi**: Ubah nama panggilan, caption foto, judul, dan isi pesan langsung di file `index.html` atau lewat tombol **Edit** di halaman web.
- **Tombol Kirim Peluk Interaktif**: Efek hujan hati dan suara denting lembut saat diklik.

## 🚀 Cara Upload & Online-kan di GitHub Pages
1. **Buat Repository Baru** di GitHub (misalnya bernama `untuk-kamu`), pilih **Public**, lalu klik **Create repository**.
2. **Upload File**:
   - Upload file `index.html` dan `README.md` dari folder ini ke repository tersebut.
   - *(Opsional tapi disarankan)* Siapkan satu foto terbaik pasanganmu, ubah namanya menjadi **`foto-pasangan.jpg`**, lalu upload ke repository yang sama agar fotonya langsung tampil otomatis saat link dibuka oleh pasanganmu!
3. **Aktifkan GitHub Pages**:
   - Buka tab **Settings** di repository GitHub kamu.
   - Pilih menu **Pages** di sebelah kiri.
   - Pada bagian **Branch**, pilih `main` (atau `master`), biarkan folder `/ (root)`, lalu klik **Save**.
4. Tunggu sekitar 1–2 menit, lalu refresh halaman Settings > Pages. Link website kamu akan muncul dan siap dikirim ke pasangan! 💖
